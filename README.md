# Cyberpunk 2077 Resource Paths

## cyberpunk2077-resource-paths.db

A SQLite database mapping 751,710 FNV1a64 file hashes to human-readable resource
paths for Cyberpunk 2077 version 2.31, including all Phantom Liberty (EP1) content.
Covers 99.97% of all files across the 32 base-game and EP1 archives.

The database is useful for any tool that needs to resolve game file hashes to
readable paths, such as mod conflict checkers, asset browsers, or modding utilities.

See [cyberpunk2077-resource-paths/README.md](cyberpunk2077-resource-paths/README.md)
for the full schema, hash algorithm, and usage examples.
